# Performance Analysis Tools

This directory contains tools for testing and analyzing the performance of the WevN backend server.

## Contents

-   **`locustfile.py`**: A load testing script using [Locust](https://locust.io/).
-   **`analyze_log.py`**: A Python script to parse and analyze the server's performance log CSV.
-   **`performance_log.csv`**: Creating during server execution (moved here for analysis).

## Usage

### 1. Load Testing with Locust

Ensure the server is running (`uvicorn server2:app --reload`), then:

```bash
# Install Locust if needed
pip install locust

# Run Locust
locust -f locustfile.py --host http://localhost:8000
```

Open your browser at `http://localhost:8089` to configure and run the load test.

### 2. Log Analysis

If you have a `performance_log.csv` file (generated by server logging middleware or manual logging), you can analyze it:

```bash
python3 analyze_log.py performance_log.csv
```

This will output:
-   Total requests & Error rates
-   Average & Max latency per endpoint
-   Status code distribution
